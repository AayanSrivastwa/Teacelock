# TeaceLock 🔐

TeaceLock is a product authenticity and supply-chain tracking system.

## Current Features

- Product registration
- Unique product codes
- SHA-256 product hashing
- QR code generation
- QR code scanning
- Product verification
- Supabase database integration
- Supply-chain event tracking

## Tech Stack

- React
- TypeScript
- Vite
- Supabase
- PostgreSQL
- QR Code
- SHA-256
